# Measurement data

These files are curated from the Paper A evidence audit. Their source digests
and scopes are indexed in `evidence-index.json` and `metadata/data-files.json`.
Evidence IDs identify records, not independent experiments or contributions.

Start with `nine-v1-repeats.csv`, `nine-results.csv`, `frozen-version.json`, and
`correctness-coverage.json`. See `docs/RESULTS.md` for the measurement contract.
Missing values remain missing. Gate thresholds are not observed errors. The
original raw trajectories and evaluator implementation are not included.
